# 11: Formatted input

Field widths leave one byte for the terminator when scanning each name.

Open Developer PowerShell for Visual Studio 2022 (Desktop development with C++ workload) in this lesson folder. Build and run:

```powershell
cl /nologo /std:c17 11_cProgramming.c /Fe:lesson.exe
'River Sky 2' | .\lesson.exe
```
